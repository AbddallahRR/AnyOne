Comic Web (Flask)
├── Backend (Python)
│   ├── app.py              — Factory de la app
│   ├── config.py           — Variables de entorno y rutas
│   ├── blueprints/
│   │   ├── main.py         — Rutas HTML (/, /serie, /reader)
│   │   └── api.py          — API REST (/api/*)
│   └── core/
│       ├── database.py     — SQLite + migraciones
│       ├── disk_cache.py   — Caché JSON en disco con TTL
│       ├── download_worker.py — Workers de descarga en threads
│       ├── sources.py      — Registro de fuentes
│       └── utils.py        — Utilidades compartidas
└── Frontend (HTML/JS/CSS)
    ├── templates/
    │   ├── base.html        — Layout base, design system CSS
    │   ├── index.html       — Página principal (búsqueda + biblioteca)
    │   ├── serie.html       — Detalle de serie + capítulos
    │   └── reader.html      — Lector (anime/manga)
    └── static/
        ├── css/
        │   ├── styles.css   — Componentes generales
        │   ├── base.css     — tokens :root, reset, body, todos los componentes reutilizables
        │   ├── layout.css   — nav, page-content, search bars, breakpoints globales
        │   ├── index.css    — filter chips de biblioteca + scroll horizontal móvil
        │   ├── serie.css    — cover parallax, heroCardIn, synopsis expand, sort/delete btns
        │   └── reader.css   — body override, reader-root, controls bar, nav buttons
        └── js/
            ├── app.js           — Lógica de index.html
            ├── serie.js         — Lógica de serie.html
            ├── reader.js        — Lógica de reader.html
            └── queue-indicator.js — Indicador flotante de descargas
